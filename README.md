# AInfographic

An infographic to quickly grasp the current state of AI and LLM's for folks in software engineering.

## Viewing

Open `index.html` directly in a browser, or run a lightweight static server:

```
npx serve .
```

No build step. Data lives in `DATA.md` (human-editable prose) and `js/data.js`
(the structured form the page actually reads). See `PLAN.md` for the
implementation plan and recorded design decisions.
